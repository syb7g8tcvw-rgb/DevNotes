CSS do básico ao avançado

Aprenda a estilizar páginas, criar layouts, usar Flexbox, Grid e responsividade.

Bloco 1 — Introdução ao CSS

CSS é a linguagem usada para dar estilo ao HTML.

body {
    background: #0f172a;
    color: white;
}

Bloco 2 — Seletores

Seletores escolhem quais elementos serão estilizados.

p {
    color: white;
}

.card {
    background: #1e293b;
}

#titulo {
    font-size: 32px;
}

Bloco 3 — Cores

Você pode usar nomes, hexadecimal, RGB e gradientes.

color: white;
background: #111827;
background: rgb(15, 23, 42);
background: linear-gradient(90deg, #3b82f6, #8b5cf6);

Bloco 4 — Box Model

Todo elemento é uma caixa com conteúdo, padding, borda e margin.

.card {
    margin: 20px;
    padding: 25px;
    border: 1px solid #334155;
    border-radius: 16px;
}

Bloco 5 — Flexbox

Flexbox ajuda a alinhar elementos em linha ou coluna.

.menu {
    display: flex;
    justify-content: space-between;
    align-items: center;
    gap: 20px;
}

Bloco 6 — Grid

Grid é ótimo para criar cards e layouts em colunas.

.grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

Bloco 7 — Responsividade

Media queries adaptam o site para celular e computador.

@media(max-width: 768px) {
    .grid {
        grid-template-columns: 1fr;
    }
}

Exercícios

1. Qual propriedade muda a cor do texto?

A) background

B) color

C) margin

Ver resposta

Resposta: B) color

2. Qual propriedade cria espaçamento interno?

A) padding

B) margin

C) border

Ver resposta

Resposta: A) padding

3. Qual comando ativa Flexbox?

A) display: block;

B) display: flex;

C) position: flex;

Ver resposta

Resposta: B) display: flex;

Flashcards

O que é CSS?

Linguagem usada para estilizar páginas HTML.

O que é padding?

Espaçamento interno de um elemento.

O que é margin?

Espaçamento externo de um elemento.

Lembretes do que eu mais erro

  • Classe no CSS usa ponto: .card
  • ID no CSS usa hashtag: #titulo
  • Padding é espaço interno.
  • Margin é espaço externo.
  • Não esquecer o ponto e vírgula no final.
  • Media query serve para responsividade.
