Módulo completo

JavaScript do básico ao avançado

Aprenda lógica, variáveis, funções, arrays, objetos, DOM e eventos.

Bloco 1 — Introdução ao JavaScript

JavaScript é usado para adicionar lógica e interatividade aos sites.

console.log("Olá, mundo!");

Bloco 2 — Variáveis

Variáveis guardam informações para serem usadas depois.

let nome = "Gui";
const idade = 18;

console.log(nome);
console.log(idade);

Bloco 3 — Tipos de dados

Os principais tipos são string, number, boolean, array e object.

let nome = "Gui";
let idade = 18;
let aprovado = true;
let linguagens = ["HTML", "CSS", "JavaScript"];

Bloco 4 — Funções

Funções são blocos de código que executam uma ação.

function saudar(nome) {
    console.log("Olá, " + nome);
}

saudar("Gui");

Bloco 5 — Arrays

Arrays são listas de informações.

let materias = ["HTML", "CSS", "JavaScript"];

materias.push("Lógica");

console.log(materias);

Bloco 6 — Objetos

Objetos guardam informações organizadas em propriedades.

let aluno = {
    nome: "Gui",
    curso: "ADS",
    semestre: 1
};

console.log(aluno.nome);

Bloco 7 — DOM

DOM permite pegar e alterar elementos do HTML com JavaScript.

let titulo = document.getElementById("titulo");

titulo.innerText = "Novo título";

Bloco 8 — Eventos

Eventos executam ações quando o usuário interage com a página.

let botao = document.getElementById("botao");

botao.addEventListener("click", function() {
    alert("Você clicou!");
});

Exercícios

1. Qual comando mostra algo no console?

A) console.log()

B) print()

C) mostrar()

Ver resposta

Resposta: A) console.log()

2. Qual palavra cria uma variável que pode mudar?

A) const

B) let

C) function

Ver resposta

Resposta: B) let

3. Qual método adiciona item em array?

A) add()

B) insert()

C) push()

Ver resposta

Resposta: C) push()

Flashcards

O que é variável?

Um espaço para guardar uma informação.

O que é função?

Um bloco de código que executa uma ação.

O que é array?

Uma lista de itens.

Lembretes do que eu mais erro

  • String precisa estar entre aspas.
  • Função precisa ser chamada para executar.
  • Array começa no índice 0.
  • Não esquecer parênteses em funções.
  • Não escrever console.log(pessoas[3], nome) se nome não existe fora do objeto.
  • Para pegar propriedade de objeto use: pessoas[3].nome
