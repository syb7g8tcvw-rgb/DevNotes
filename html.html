HTML do básico ao avançado

Aprenda a estrutura das páginas web, tags, formulários, tabelas, semântica e boas práticas.

Bloco 1 — Introdução ao HTML

HTML significa HyperText Markup Language. Ele é usado para estruturar o conteúdo de páginas web.

Bloco 2 — Estrutura básica

Todo documento HTML precisa de uma estrutura inicial.

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Minha página</title>
</head>
<body>
    Conteúdo visível
</body>
</html>

Bloco 3 — Títulos e textos

Use títulos para organizar a hierarquia da página.

<h1>Título principal</h1>
<h2>Subtítulo</h2>
<p>Parágrafo de texto</p>
<strong>Texto importante</strong>
<em>Texto enfatizado</em>

Bloco 4 — Links

Links servem para navegar entre páginas ou sites externos.

<a href="index.html">Voltar para início</a>
<a href="https://google.com" target="_blank">Abrir Google</a>

Bloco 5 — Imagens

A tag img exibe imagens. O atributo alt melhora acessibilidade.

<img src="imagem.jpg" alt="Descrição da imagem">

Bloco 6 — Listas

Listas podem ser ordenadas ou não ordenadas.

<ul>
    <li>HTML</li>
    <li>CSS</li>
</ul>

<ol>
    <li>Primeiro passo</li>
    <li>Segundo passo</li>
</ol>

Bloco 7 — Formulários

Formulários coletam informações do usuário.

<form>
    <label>Nome:</label>
    <input type="text" placeholder="Digite seu nome">

    <label>Mensagem:</label>
    <textarea></textarea>

    <button>Enviar</button>
</form>

Bloco 8 — Tabelas

Tabelas organizam dados em linhas e colunas.

<table>
    <tr>
        <th>Nome</th>
        <th>Idade</th>
    </tr>
    <tr>
        <td>Gui</td>
        <td>18</td>
    </tr>
</table>

Bloco 9 — HTML Semântico

HTML semântico deixa o código mais organizado e profissional.

<header></header>
<nav></nav>
<main></main>
<section></section>
<article></article>
<footer></footer>

Exercícios

1. Qual tag cria o maior título?

A) <p>

B) <h1>

C) <div>

Ver resposta

Resposta: B) <h1>

2. Qual tag cria um link?

A) <a>

B) <img>

C) <section>

Ver resposta

Resposta: A) <a>

3. Qual atributo melhora acessibilidade em imagens?

A) href

B) src

C) alt

Ver resposta

Resposta: C) alt

Flashcards

O que é HTML?

Linguagem de marcação usada para estruturar páginas web.

Para que serve o body?

Para colocar o conteúdo visível da página.

Para que serve o alt?

Para descrever imagens e melhorar acessibilidade.

Lembretes do que eu mais erro

  • Não esquecer o <!DOCTYPE html>.
  • Fechar corretamente as tags.
  • Usar apenas um h1 principal por página.
  • Não esquecer o atributo alt nas imagens.
  • Links precisam do atributo href.
  • O conteúdo visível fica dentro do body.
